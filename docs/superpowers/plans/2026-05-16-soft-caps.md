# Plan — Soft-Caps für `permanent_multiplier`

TDD-Reihenfolge. Jeder Task = ein Commit. Tests müssen rot werden, bevor Code
geschrieben wird.

## Task 1 — `PrestigeManager.total_stars_earned` + Recompute-Helper

**Code:**
- Neues Feld `var total_stars_earned: int = 0` in `prestige_manager.gd`.
- Neue Konstante `const MULT_BASE: float = 0.15` (Economy oder PrestigeManager — Economy ist näher am Multiplier).
- Neue Methode `Economy._recompute_permanent_multiplier(total_stars: int) -> void` setzt das Feld nach der Formel.
- `PrestigeManager.prestige()` ersetzt die `+=`-Zeile durch:
  ```
  total_stars_earned += gained
  Economy._recompute_permanent_multiplier(total_stars_earned)
  ```
- `PrestigeManager.reset()` setzt `total_stars_earned = 0` zurück.

**Tests (`test/test_prestige.gd`):**
- `test_total_stars_earned_accumulates` — zwei Prestiges erhöhen Counter korrekt.
- `test_permanent_multiplier_follows_log_curve` — nach Prestige mit bekannter Star-Zahl prüft die Kurve auf 1e-4.
- `test_multiplier_monotonic_over_prestiges` — Multiplier wird über drei Prestiges nie kleiner.
- Bestehende Tests anpassen: Werte, die `+= 0.01` erwarten, auf neue Kurve umstellen oder auf Star-Counter umstellen.

## Task 2 — Save/Load mit Migration

**Code:**
- `PrestigeManager.serialize()` ergänzt um `"total_stars_earned"`.
- `PrestigeManager.deserialize(data)`: liest neuen Key; falls fehlend, ruft `_migrate_from_legacy(economy_legacy_mult)` und setzt Counter aus `(mult-1)*100`.
- Migration braucht Zugriff auf den alten Economy-Multiplier — am sauberften: `SaveSystem.load()` orchestriert die Reihenfolge (Economy.deserialize zuerst → PrestigeManager kann Economy-Mult lesen).
- Nach beidem Deserialize: `Economy._recompute_permanent_multiplier(PrestigeManager.total_stars_earned)` zwingend aufrufen — überschreibt den aus dem alten Save geladenen `permanent_multiplier`-Wert.

**Tests (`test/test_prestige.gd` + `test/test_save_system.gd` falls vorhanden, sonst in test_prestige):**
- `test_save_roundtrip_preserves_total_stars` — Save → neu instanziieren → Load → Counter identisch, Mult identisch.
- `test_legacy_save_migrates_to_total_stars` — Save-Dict ohne `total_stars_earned`, nur mit `permanent_multiplier=1.50` → nach Load `total_stars_earned=50` und Mult ≈ 1.590.
- `test_legacy_save_with_mult_1_0_migrates_to_zero_stars` — Edge-Case: alter Save ohne Prestiges.

## Task 3 — Bestehende Tests auf neue Kurve umstellen

`test_economy.gd` und `test_prestige.gd` durchgehen. Vermutlich betroffen:
